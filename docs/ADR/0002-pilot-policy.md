# ADR-0002 — 2026-10-27 파일럿 서비스 정책

Status: 운영자 승인. 실제 기능 구현·외부 전송 고지 확인·파일럿 시작은 후속 검증 대상.

승인자: 서비스 운영자 hyunhomon. 근거: #5의 15개 질문에 대한 사용자 답변 및 문의/삭제 기한 후속 답변. 실제 학생 동의·교수의 루브릭 승인·학교 승인으로 확대 해석하지 않는다.

## 결정

1. 성인 내부 실험, 4명×20팀, 약 2개월. 성적 반영 없이 교수 참고·피드백과 제품 검증에 사용한다. 서비스의 근거 제공과 교수의 판단을 구분한다.
2. 교수의 오프라인 동의서 확보 후 학생이 QR 체크박스로 같은 서류 동의를 재확인한다. 수업·학생·계정·버전·증빙 참조와 연결한다.
3. 전원 사전 동의·고정 참가자/고지문을 전제로 비동의·신규 가입·개정 전용 UI와 대체 평가 구현은 제외한다. 교수 안내와 미확인 상태의 처리 차단은 유지한다.
4. 동의 전 수집/백필 금지와 지정 채널·활성 허용 구간 경계는 유지한다.
5. Slack은 원문 저장소다. 서비스에는 링크 세트·변경 검증 metadata·요약·결과를 보관하고 대화/이미지 원본·전체 payload는 실행 중에만 처리한다. 기존 원문 컬럼을 이번 문서 변경에서 삭제하지 않는다.
6. 리포트 열람·확정·출력 전에 현재 원문과 요약을 재검증한다. 수정·삭제·불일치 링크는 유효 근거에서 제외하고 결과를 무효화한다. 요약 수정은 새 버전과 교수 재검토를 거친다. Slack 장애와 실제 삭제는 구분한다.
7. 철회·원문 변경의 영향은 교수 확정본에도 적용한다. 즉시 사용 중지/무효화 후 허용 자료로만 재분석한다. 무효화와 물리 삭제 시점을 구분한다.
8. 요약·리포트·근거 링크 및 관련 동의/감사 이력은 수업 종료 후 3개월에 삭제한다. 무효화된 요약·리포트도 동일 기준이며 3개월을 90일로 바꾸지 않는다. 별도 조기 삭제 요청을 일괄 거절하는 정책으로 해석하지 않는다.
9. 학생 웹 문의의 답변 기한은 교수 설정 n일이다. 문의 접수 시각+n일에 답변 여부와 관계없이 문의·답변을 자동 삭제한다. n의 기본 숫자는 정하지 않으며 적용 기한을 학생에게 표시한다.
10. 교수는 자기 수업만 접근하고 운영자의 원문 접근은 기본 금지, 승인된 장애 조사만 감사 기록과 함께 허용한다.
11. 담당 교수 이메일/웹 문의 기록을 제공한다. 학생 본인 피드백 요청 시 교수가 최신 리포트를 출력해 타인 정보와 검토 상태를 확인하고 전달한다. 학생용 평가 열람 포털은 추가하지 않는다.

## 남은 확인과 인수인계

- 실행 중 외부 모델 전송은 계속 필요하다. 식별자/이미지 가림 수준과 모델별 보관·학습 사용·처리 지역·고지의 일치는 #15 및 시작 전 확인 사항이다. 답변 10의 저장 전략 변경을 전송 세부 조건의 승인으로 추정하지 않는다.
- 실제 수업 일자·담당 교수 이메일·오프라인 서류 버전/증빙·QR 학생 식별·문의 기한 설정은 후속 기능에서 구체화한다. 공개 저장소/이슈에 학생 자료를 올리지 않는다.
- [PRIVACY_AND_DATA.md](../PRIVACY_AND_DATA.md)의 상태표를 #8/#14/#24 테스트 사례로 사용한다. 원문 저장 전제의 이슈/설계는 참조·요약 기반으로 갱신한다.
- 추가 기능은 #29 학생 QR(M2, 민지), #30 문의 n일 자동 삭제(M5, hyunhomon), #31 교수 리포트 출력(M5, 민지)으로 추적하고 #24 통합 검증의 선행 관계에 연결한다.
- 이번 변경은 문서/업무 계획이다. 기능 구현·DB 컬럼/동의 이력 삭제·수집 활성화·production 배포를 수행하지 않는다.

2026-10-27 후속: 위 #15 미확정 항목 중 개발용 선택 루브릭·Qwen 모델/경로·실제 표시명/프로젝트 이미지 원본 전송·ZDR 결정은 [ADR-0003](0003-rubric-model-profile.md)으로 구체화했다. 실제 고지·처리 지역·계정 logging·품질 확인은 시작 전에 남아 있다.
