# Evaluation Rubric — 4 competencies (draft)

**주의:** 인터뷰에서 확정한 '4개 역량별 정성 판단+근거' 출력 요구에 맞춰 아래 하위 이름은 **제안 초안**이다. 운영 루브릭으로 확정되지 않았다.

| 역량(제안) | 관찰 가능 행동 | 금지된 대리 지표 | 근거 부족일 때 |
|---|---|---|---|
| 1. 정보 전달의 명료성 | 질문의 대상/의도 명확화, 상황·제약 정리, 오해 해소 | 긴 메시지·메시지 수 | 관찰 불충분 |
| 2. 정보 공유·협업 지원 | 관련 자료 적시 공유, 요청에 실질 답변, 막힌 동료 지원 | 링크 수·답장 수 | 관찰 불충분 |
| 3. 피드백 수용·상호 조율 | 타인 의견 확인, 합리적 반론, 대안 제안, 수정 반영 | 무조건 동의·이모지 수 | 관찰 불충분 |
| 4. 의사결정·실행 연결 | 합의 내용 정리, 책임/다음 행동 명료화, 변화 상황 공유 | 회의 주도 횟수 | 관찰 불충분 |

## 출력 구조

각 학생·역량별: `judgement`(observed_strength / mixed / needs_support / insufficient_evidence), `narrative`, `evidence_ids[]`, `counter_evidence_ids[]`, `confidence`, `limitations`, `requires_human_review`.

## 원칙

- 근거 없는 0점/낙제 금지. 기회를 가질 수 없었던 행동에 감점 금지.
- 활발한 발언과 유익한 발언 구분. 팀에서 맡은 역할/맥락 고려.
- 공격적 표현도 전체 대화·반응·후속 조치 없이 단편 평가 금지.
- 결측 기간, 오프라인 협업, 다른 협업 툴 사용은 제한으로 명시.
- 평가 불일치 사건은 교수 확인 대상으로 표시.
- 내용상 개인정보, 건강, 정치 성향, 사적 관계를 평가 근거로 사용하지 않음.

## 신뢰도 검증

파일럿에서 익명화한 실제 대화 사례를 교수/조교 평가자 두 명 이상이 블라인드 채점한다. 근거 정합성, 하위 역량별 동의율, 지나친 발언량 편향, 역할별 편향, 고성취자의 변별력 및 평가에 대한 이의제기 가능성을 기록한다.
