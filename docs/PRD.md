# PRD — TeamPlanet MVP

## 1. 문제

결과물의 완성도가 생성형 AI로 상향 평준화되는 상황에서 교수는 개별 학생이 **팀 프로젝트 과정에서 어떻게 소통하고 협력했는지** 직접 관찰하기 어렵다. 기존 동료평가·중간보고는 회고 중심이어서 실제 대화 맥락이 충분히 드러나지 않을 수 있다.

## 2. 제품 가설

학생에게 추가 기록 업무를 부과하지 않고, 이미 사용하는 **Slack의 지정된 프로젝트 채널 전체 대화**를 AI가 분석하면 교수는 기존 평가 과정을 보완할 **근거 기반 커뮤니케이션 관찰 자료**를 얻는다.

> 제품 목표는 커뮤니케이션 행위의 **증거 있는 관찰**이며, AI가 사람의 내적 역량을 객관적으로 확정하거나 자동으로 성적을 매기는 것이 아니다.

## 3. 사용자

- **교수/조교:** 프로젝트 채널 구성, 분석 기간 선정, 평가 결과 검토, 근거 열람, 수정·확정
- **학생:** 팀 채널에서 평소처럼 소통, 수집 범위·동의·정정 경로 확인, 본인 피드백 조회(후속)
- **운영자:** 단일 파일럿 워크스페이스 연결 및 권한·삭제 운영

파일럿은 성인 내부 실험(4명×20팀, 약 2개월)이며 성적에 반영하지 않는 교수 참고·피드백/제품 검증용이다. 서비스 정책은 운영자가, 루브릭과 평가 판단은 교수가 담당한다. 확정 기록은 [ADR-0002](ADR/0002-pilot-policy.md)를 따른다.

## 4. 필수 사용자 흐름

1. 교수가 이메일 OTP로 접속.
2. Slack 마법사를 진행하여 단일 워크스페이스 연결.
3. 팀별 공식 채널 생성(템플릿), 봇 주입, 참가자 초대, 사전 고지와 동의 상태 확보.
4. 활성화 이후 지정된 채널의 메시지, 스레드, 필요한 이미지 첨부를 수집.
5. 교수가 팀과 시작·종료일을 지정하고 **분석 실행**.
6. 3모델 단계별 분석 → 구조화 근거 추출 → 역량별 정성 판단 → 비판적 검토.
7. 교수는 초기 선택한 역량 각각 **판단·근거·불확실성**을 검토하고 필요 시 정정.

## 5. 필수 기능

- Slack OAuth / 연결 상태 / 지정 채널 관리 / 봇 설치 상태 표시
- 사용자별 수집 고지·동의 상태 기록(동의 전 활성화 차단)
- 대화·스레드·이미지 참조 수집 및 처리 상태
- 기간 지정 수동 분석 실행 및 재실행(버전 남김)
- 네 역량 중 교수 선택 항목별 정성 평가 / 링크 가능한 발화 근거 / 반례 및 근거 부족 표기
- 교수용 결과 뷰 및 근거 열람
- AI 판단에 대한 사람의 확정/수정 내역 감사 로그
- 공급자 거절·권한·잔액·일시 장애 상태 구분
- 교수의 오프라인 동의 확보와 학생 QR 체크박스 재확인, 수업/학생/계정/서류 버전 연결
- 원문/이미지 장기 복제 없이 Slack 재조회와 링크·revision/지문·요약 중심 보관
- 리포트 열람·확정·출력 전 정합성 검증, 원문 변경 시 교수 확정본까지 무효화·재검토
- 담당 교수 이메일·학생 웹 문의, 접수 후 교수 설정 n일 자동 삭제
- 교수가 검증된 리포트를 출력해 학생 본인 피드백으로 전달, 수업 종료 후 3개월 자료 삭제

## 6. MVP 제외

- 학생에게 강제하는 태스크 보드, 이슈 작성, 주간 보고서
- 범위 밖 대화/DM 감시
- 자동 주기 평가, 자동 점수 제출, 학생 간 공개 랭킹
- 여러 대학·여러 Slack 워크스페이스 운영 기능
- 사용자 지정 앱 토큰·비용 예산 및 소프트 스펜딩 가드
- 파일럿의 비동의자 대체 평가·신규 가입·고지문 개정 전용 UI(교수 안내와 미확인 상태 처리 차단은 유지)
- 학생용 평가 열람 포털(학생 QR 재확인/본인 문의 페이지는 포함)

## 7. 성공 기준 — 파일럿에서 측정

- 추가 학생 입력 없이 분석이 완료되는가?
- 모델이 주장하는 모든 평가는 **원문 메시지 ID/링크**로 역추적 가능한가?
- 숙련 평가자 2명이 블라인드로 판정한 관찰과 **방향성 합치**가 어느 정도인가?
- 말 수/채널 활성도만으로 좋은 평가가 발생하지 않는가?
- 학생이 분석 대상을 예측하고 거부·정정 수단을 이해하는가?
- 교수 검토 시간은 기존 보고서/동료평가 대비 유의미하게 줄어드는가?

## 8. 미해결 정책

서비스 정책은 [PRIVACY_AND_DATA.md](PRIVACY_AND_DATA.md)의 상태표를 따른다. 전원 사전 동의·고정 참가자/서류를 전제로 대체 평가 구현은 제외하며 전제 위반 시 자동 승인하지 않는다. 요약·리포트는 수업 종료 후 3개월, 웹 문의는 접수 후 교수 설정 n일에 삭제한다. 선택형 루브릭·Qwen/DeepInfra ZDR·이름/이미지 전송 결정은 ADR-0003을 따른다. 실제 고지·처리 조건·품질 확인은 파일럿 시작 전에 수행한다.
